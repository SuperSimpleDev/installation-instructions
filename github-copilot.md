## How to Install GitHub Copilot
1. Follow these instructions: https://code.visualstudio.com/docs/copilot/setup#_set-up-copilot-in-vs-code
2. You can also click the copilot icon in VSCode and it should have some instructions on how to set it up.<br>

## Troubleshooting
You'll need the GitHub Copilot extensions installed for it to work.
1. Usually if you follow the instructions at the top, it will install the extensions automatically.

2. If it doesn't work, open the extensions section in VSCode<br>
<img height="200" src="https://github.com/user-attachments/assets/e89a607c-2bb8-4278-8b11-f5d228ed1a9b">

3. Search for "github copilot"<br>
<img height="200" src="https://github.com/user-attachments/assets/93e8c27e-640e-44bc-9953-8c4091532b3a">

4. Install the GitHub Copilot extension. It should also install GitHub Copilot Chat automatically.
