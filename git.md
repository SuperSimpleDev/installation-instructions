## How to Install Git
### Windows
1. Open https://git-scm.com/downloads/win
2. Click the download link
3. Double-click the downloaded file to open the installer
4. Keep clicking Next until Git is installed (go with the default options for each step)

### Mac
1. Open Terminal (press Command + Space and search for "Terminal")
2. Type `git` in the Terminal and press `Enter`
3. If Git is not installed, it will open a popup asking if you want to install Git (if Git is already installed, it will just display some info in the Terminal)
4. Click "Install" in the popup

### Linux
1. Open https://git-scm.com/downloads/linux
2. Follow the instructions for your Linux distribution
